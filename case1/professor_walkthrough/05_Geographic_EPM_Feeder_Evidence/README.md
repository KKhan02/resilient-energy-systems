# Moving from hypothetical feeders to EPM-mapped conductor sections

The EPM GIS archive provides transformer IDs, node connectivity and mapped LV segments. We reconstructed these links and attached the household points through explicit assumed service connections. The older MST/star sensitivity remains useful as a methodological comparison, but it is not the primary feeder baseline after obtaining the GIS data.
