# First electrical falsification: aggregate feasibility is not AC feasibility

We took the optimized net injections into a representative 5 kVA radial pandapower network. The 5–15 household sweep showed undervoltage even when an aggregate transformer-import proxy passed. This initial feeder was intentionally generic; its 324.5 m extent is not the recorded physical layout of the selected EPM territories.
