# B3 pilot: matched load-only AC comparison

Proposed, bounded first AC campaign after verified geometry. Retain all 3,146 candidates; no gross-only exclusion. Choose up to four site pairs per N=5–15 using reproducible criteria: median cable saving, largest relative path increase, shortest absolute MST path, and highest coincident gross peak (ties favor shorter MST cable). Deduplicate identical sites. This is diagnostic sampling, not an exhaustive feasibility frontier and not a final geometry choice. The geometric nondominance flag is not an AC filter.

Use exact frozen per-house profiles, same selected hours within each site pair. Shared hours include top three aggregate load hours, lowest gross hour, each household peak, each branch downstream peak and each root-to-node weighted path load peak across both topologies. Last proxy selects stress snapshots, not solved voltage. Apply reference PF .98 route x1 and severe .95 x1.6, both uniform AAC 4 and AAC 1/0 proxy alternatives, 5 kVA unchanged. These are exploratory parameter choices under existing Study A conventions, not surveyed conductor allocation or final sizing. Reuse existing EPM build_net, with an adapter for B nodes and edges, including co-located supply/house; no zero-length branch. No inverter injection, no LP, no annual AC. Preserve nonconvergence and violations, report power balance and physical kW loss at sampled hours only. Do not extrapolate annual loss or failure hours.

Preflight verifies ten signed tables, frozen annual loads, exact equivalent scaling and conductor values, topology counts and paired smoke AC. After successful pilot, examine actual matched performance, expand coverage and all nine PF/route factors where relevant, then compare fixed PV/BESS hardware and exact-cohort dispatch. Do not extrapolate to outages or field compliance.
