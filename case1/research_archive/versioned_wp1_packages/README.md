# WP1 historical version-transfer packages

The ZIP files in this folder are **frozen research transfer packages** previously stored at the GitLab repository root. They reflect successive development and patch versions of the AC feedback, voltage-band, robustness and full-campaign reuse work.

- Current executable modules and tests are under [`case1/studies/ac_aware_redispatch_v1/`](../../studies/ac_aware_redispatch_v1/), not inside these historical ZIPs.
- These archives are **not** a single installation sequence or a recommended source of executable truth. Their contents may differ from the current checked-in Python.
- Source `README`, study manifests, archived results and test histories remain at their original locations.
- Files were moved without re-creating or modifying their bytes. Git records the change. Refer to [`RELOCATION_INDEX.csv`](../RELOCATION_INDEX.csv) for each previous path.
